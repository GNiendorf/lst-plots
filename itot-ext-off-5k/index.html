Pixel tracks without the outer-tracker extension: tracking validation

Phase-2 HLT, CPU menu (serial backend), D121, PU200. Produced 2026-10-17 (5k sample; the 1k pages of 2026-10-14 are a subset of these events).

Configurations (one curve each)

#290the base PR as is: pixel tracks extended into the outer tracker.
Extension off#290 with the pixel-track extension into the outer tracker turned off (pixel-only pixel-track configuration), no LST or mkFit changes.
Extension off + LST/mkFit changesExtension off plus this study's LST changes (new track candidates from outer-tracker triplets and pixel-less T5s completed with pixel doublets handed over by the pixel tracking; pT5 ranking and selection) and mkFit duplicate removal against surviving tracks only.

Events

ttbar: 5000 events (3496 reach HLT tracking); QCD (pT-hat 1.8-2.4 TeV): 5000 events (5000 reach HLT tracking). The same events in all three configurations. None of these events was used to develop or tune the changes.
